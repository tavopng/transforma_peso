# Conversor a Kilos o Libras
Una página para traducir kilos a libras y viceversa

## Cómo usarla
1. Indica tu nombre, tu peso, y la unidad a la que quieres convertir
2. Dale al botón enviar

## Cositas que aprendí
Aprendí a tomar los inputs de los usuarios para hacer uso de ellos en funciones de Javascript, dando un paso a crear sitios interactivos
